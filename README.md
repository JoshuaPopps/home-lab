# Home Lab

My home lab — spare parts, old hardware, and stubbornness. Glendale, AZ.

## The stack

- **Umbrel server** (HP Compaq Elite 8300, i7/16GB) — the always-on box. Pi-hole for network-wide ad blocking, Immich for photo backup, Plex + Threadfin for OTA live TV, Home Assistant for the smart home.
- **Hades Canyon NUC** (Windows 11 Pro, 32GB) — download box behind VPN, Plex server, and local AI (Ollama + Open WebUI).
- **Dell laptop** — daily driver, on the tailnet.
- **Tailscale** — ties it all together; everything's reachable from anywhere.

## Notes

- Storage: a 2.7TB GoFlex drive on the Umbrel box holds media, photo backups, and archives.
- Backups: the important stuff gets backed up. The rest is a learning experience.
- Power: the whole lab sips power — the NUC running local AI costs a few bucks a month.
